Frequently asked questions

Quick answers about adding, using, and troubleshooting ZERObot.

What is ZERObot?

ZERObot is an all-in-one Discord bot for server management, community building, and entertainment.

How do I add ZERObot to my server?

Click Add to Discord, choose your server, and approve the permissions. You need the Manage Server permission on that server.

Is ZERObot free?

Yes. ZERObot is free to add and use.

The slash commands aren't showing up. What do I do?
  • Type / and wait a few seconds for the list to load.
  • Make sure ZERObot is in your server's member list and shows as online.
  • Check that the bot can see the channel and that Discord's "Use Application Commands" permission is allowed for you there.
  • If it still doesn't work, remove the bot and add it again using the Add to Discord button, then ask in the support server.
Why do I get "I'm missing permissions" or "my role isn't high enough"?

Discord only lets a bot act on members and roles below its own highest role. Open Server Settings → Roles and drag the ZERObot role above the roles it should manage. Also check that the role has the permission that command needs (see the Commands page).

How does leveling work?

Members earn a small amount of XP when they send a message, at most once per minute. Spamming doesn't help. Use /rank to see your level and /leaderboard to see the top members.

How do I set up welcome messages and auto-roles?

Use /setwelcome to choose a channel and message (put {user} and {server} in it), and /setautorole to pick a role new members receive. Turn welcome messages off any time with /welcome_off.

What data does ZERObot store?

Discord user IDs, server IDs, XP, warnings, and your server settings. ZERObot does not store the text of messages. Details are in the Privacy Policy.

How do I delete my data?

Email z.ero.bot.2008z@gmail.com with your Discord user ID (and server ID if it's about a server). Server admins can also remove the bot, which deletes that server's data.

ZERObot is offline. What happened?

It may be restarting or being updated. Give it a few minutes, then check the support server for announcements.

How do I report a bug or suggest a feature?

Join the support server or use the Support page.
